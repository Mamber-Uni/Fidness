# Fidness

Proyecto realizado para el curso Programación Cliente-Servidor Concurrente.

## Descripción

Fidness es una aplicación para gestionar ejercicios y rutinas de entrenamiento.

La aplicación permite:

- Iniciar sesión con usuario y contraseña.
- Consultar ejercicios disponibles.
- Filtrar ejercicios por tipo.
- Ver información de cada ejercicio.
- Crear rutinas.
- Agregar ejercicios a una rutina.
- Guardar y consultar rutinas.

## Tecnologías utilizadas

- Java
- Java Swing
- NetBeans
- Maven
